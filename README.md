# NeuraFlow — AI Startup

Premium futuristic 5-page AI startup website built with Next.js + TypeScript.

## Pages
- `/` — Home
- `/product` — Product
- `/solutions` — Solutions
- `/pricing` — Pricing
- `/contact` — Contact

## Run locally
```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Build
```bash
npm run build
npm start
```

No external image assets are required; the hero uses CSS-generated neural visuals for fast loading and easy deployment to Vercel.
